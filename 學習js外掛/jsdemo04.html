DEMO 04 / 地圖互動

Leaflet

在網頁顯示可縮放地圖、標記地點。像店家位置、旅遊景點地圖。

L.map()、L.marker()

動手試試

拖曳地圖、縮放，並點一個位置。地圖圖磚需要網路；正式大量使用前請閱讀 OpenStreetMap 圖磚使用政策。

點地圖任意位置，查看經緯度。

讀懂這個範例

先用 HTML 放好畫面，再載入外掛的 CSS（若有）與 JavaScript，最後執行下面的初始化程式。把這個 HTML 檔複製一份，改設定練習。

① 引入外掛

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/leaflet@1.9.4/dist/leaflet.css">
<script src="https://cdn.jsdelivr.net/npm/leaflet@1.9.4/dist/leaflet.js"></script>

② 準備畫面

<div id="map" style="height:350px" aria-label="台北互動地圖"></div><p id="result" role="status">點地圖任意位置，查看經緯度。</p>

③ 啟動功能

const map = L.map('map').setView([25.033,121.5654], 14);
L.tileLayer('https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png', {
  maxZoom:19, attribution:'&copy; <a href="https://www.openstreetmap.org/copyright">OpenStreetMap</a> contributors'
}).addTo(map);
L.marker([25.033,121.5654]).addTo(map).bindPopup('台北 101 附近').openPopup();
map.on('click', event => {
  document.querySelector('#result').textContent = '緯度 ' + event.latlng.lat.toFixed(5) + '，經度 ' + event.latlng.lng.toFixed(5);
});
閱讀 Leaflet 官方文件 ↗

範例固定版本，方便重複練習；官方文件可能已更新。若改用新版，請對照該版本 API。資料僅在瀏覽器示範。
