DEMO 03 / 3D 模擬

Three.js

在網頁放入有立體感的物件。像商品展示；這裡用旋轉方塊練習場景、相機和模型。

THREE.Scene()、THREE.Mesh()

動手試試

點按鈕暫停；把 BoxGeometry 的第一個 1 改成 2，看寬度變化。此範例固定使用 0.160.1 的傳統 script 版，較新版請依官方文件改用 ES module。

讀懂這個範例

先用 HTML 放好畫面，再載入外掛的 CSS（若有）與 JavaScript，最後執行下面的初始化程式。把這個 HTML 檔複製一份，改設定練習。

① 引入外掛

<script src="https://cdn.jsdelivr.net/npm/three@0.160.1/build/three.min.js"></script>

② 準備畫面

<div id="scene" style="height:320px;overflow:hidden;border-radius:16px"></div><button id="pause" aria-pressed="false">暫停旋轉</button>

③ 啟動功能

const host = document.querySelector('#scene');
const scene = new THREE.Scene();
scene.background = new THREE.Color('#152e35');
const camera = new THREE.PerspectiveCamera(60, host.clientWidth / host.clientHeight, 0.1, 100);
camera.position.z = 3;
const renderer = new THREE.WebGLRenderer({antialias:true});
renderer.setPixelRatio(Math.min(devicePixelRatio,2));
renderer.setSize(host.clientWidth, host.clientHeight);
host.appendChild(renderer.domElement);
const cube = new THREE.Mesh(new THREE.BoxGeometry(1,1,1), new THREE.MeshNormalMaterial());
scene.add(cube);
let running = true;
document.querySelector('#pause').onclick = event => {
  running = !running;
  event.target.textContent = running ? '暫停旋轉' : '繼續旋轉';
  event.target.setAttribute('aria-pressed', String(!running));
};
renderer.setAnimationLoop(() => {
  if(running){ cube.rotation.x += 0.008; cube.rotation.y += 0.012; }
  renderer.render(scene,camera);
});
new ResizeObserver(() => {
  camera.aspect = host.clientWidth / host.clientHeight;
  camera.updateProjectionMatrix(); renderer.setSize(host.clientWidth,host.clientHeight);
}).observe(host);
