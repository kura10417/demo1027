DEMO 08 / 提示視窗

SweetAlert2

用好看的視窗詢問或提示。像確認報名、顯示成功訊息；也能取得使用者按下的選項。

Swal.fire()

動手試試

打開視窗，分別試試確認和取消，觀察文字不同。

這是練習，不會送出報名資料。

讀懂這個範例

先用 HTML 放好畫面，再載入外掛的 CSS（若有）與 JavaScript，最後執行下面的初始化程式。把這個 HTML 檔複製一份，改設定練習。

① 引入外掛

<script src="https://cdn.jsdelivr.net/npm/sweetalert2@11.17.2/dist/sweetalert2.all.min.js"></script>

② 準備畫面

<button id="signup">模擬報名課程</button><p id="result" role="status">這是練習，不會送出報名資料。</p>

③ 啟動功能

document.querySelector('#signup').onclick = async () => {
  const result = await Swal.fire({title:'要參加 JS 入門課嗎？',text:'這只是示範，沒有實際報名。',icon:'question',showCancelButton:true,confirmButtonText:'我要練習',cancelButtonText:'再想一下'});
  document.querySelector('#result').textContent = result.isConfirmed ? '已確認！一起開始練習。' : '已取消，可以隨時再試。';
};
