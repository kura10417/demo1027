DEMO 05 / 互動表格

Tabulator

讓表格能排序、篩選和編輯。像學生名單、庫存管理；比自己重寫整套表格省時間。

new Tabulator()、setFilter()

動手試試

輸入姓名試試搜尋，再清空搜尋，點「學習時數」標題排序。

點欄名排序；點學習時數可修改。修改僅保留於本次畫面，重新整理會還原。

讀懂這個範例

先用 HTML 放好畫面，再載入外掛的 CSS（若有）與 JavaScript，最後執行下面的初始化程式。把這個 HTML 檔複製一份，改設定練習。

① 引入外掛

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/tabulator-tables@6.3.1/dist/css/tabulator.min.css">
<script src="https://cdn.jsdelivr.net/npm/tabulator-tables@6.3.1/dist/js/tabulator.min.js"></script>

② 準備畫面

<label for="search">搜尋姓名</label><input id="search" placeholder="例如：小安"><div id="grid"></div><p>點欄名排序；點學習時數可修改。修改僅保留於本次畫面，重新整理會還原。</p>

③ 啟動功能

const table = new Tabulator('#grid', {
  layout:'fitColumns', data:[{name:'小安',hours:12},{name:'小美',hours:8},{name:'阿明',hours:20}],
  columns:[{title:'姓名',field:'name'},{title:'學習時數',field:'hours',sorter:'number',editor:'number',validator:['required','numeric','min:0']}]
});
document.querySelector('#search').oninput = event => {
  table.setFilter('name','like',event.target.value); // 名字包含輸入文字才顯示。
};
