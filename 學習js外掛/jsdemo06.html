DEMO 06 / 網頁動畫

GSAP

用程式控制物件移動、轉動和透明度。像按鈕特效、首頁進場動畫。

gsap.to()、gsap.set()

動手試試

按播放看方塊移動；把 duration 改成 3，動畫會變慢。

JS

讀懂這個範例

先用 HTML 放好畫面，再載入外掛的 CSS（若有）與 JavaScript，最後執行下面的初始化程式。把這個 HTML 檔複製一份，改設定練習。

① 引入外掛

<script src="https://cdn.jsdelivr.net/npm/gsap@3.12.7/dist/gsap.min.js"></script>

② 準備畫面

<div class="track"><div id="box" class="box">JS</div></div><button id="play">播放動畫</button>

③ 啟動功能

document.querySelector('#play').onclick = () => {
  gsap.killTweensOf('#box'); // 連點時先停止上一段動畫。
  gsap.set('#box',{x:0,rotation:0});
  const distance = document.querySelector('.track').clientWidth - 72;
  gsap.to('#box', {x:distance,rotation:360,duration:1.5,ease:'power2.inOut'});
};

範例固定版本，方便重複練習；官方文件可能已更新。若改用新版，請對照該版本 API。資料僅在瀏覽器示範。
