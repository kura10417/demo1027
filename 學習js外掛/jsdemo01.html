DEMO 01 / 表單輔助

Flatpickr

把普通輸入框變成日期選擇器。像訂餐、預約看診，不必讓使用者自己打日期。

flatpickr()

動手試試

點輸入框，選一個日期；試著把 dateFormat 改成 Y/m/d。

請選擇今天或之後的日期。

讀懂這個範例

先用 HTML 放好畫面，再載入外掛的 CSS（若有）與 JavaScript，最後執行下面的初始化程式。把這個 HTML 檔複製一份，改設定練習。

① 引入外掛

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/flatpickr@4.6.13/dist/flatpickr.min.css">
<script src="https://cdn.jsdelivr.net/npm/flatpickr@4.6.13/dist/flatpickr.min.js"></script>

② 準備畫面

<label for="date">預約日期</label><input id="date" placeholder="點這裡選日期"><p id="result" role="status">請選擇今天或之後的日期。</p>

③ 啟動功能

// 找到輸入框，設定日期格式與最早日期。
flatpickr('#date', {
  dateFormat: 'Y-m-d', minDate: 'today', disableMobile: true,
  onChange: (_, text) => { document.querySelector('#result').textContent = '你預約了：' + text; }
});
