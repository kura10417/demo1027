DEMO 09 / 拖曳排序

SortableJS

用滑鼠或手指調整順序。像待辦清單排優先順序、調整商品展示位置。

new Sortable()

動手試試

把第三項拖到第一項；也可以按 Tab 移到 ↑ 按鈕，再按 Enter。

  • 讀懂範例
  • 改一個設定
  • 做自己的作品

拖曳清單，或使用 ↑ 按鈕排序。重新整理會還原。

讀懂這個範例

先用 HTML 放好畫面，再載入外掛的 CSS（若有）與 JavaScript，最後執行下面的初始化程式。把這個 HTML 檔複製一份，改設定練習。

① 引入外掛

<script src="https://cdn.jsdelivr.net/npm/sortablejs@1.15.6/Sortable.min.js"></script>

② 準備畫面

<ul id="tasks" class="tasks"><li>讀懂範例 <button class="up" aria-label="讀懂範例往上移">↑</button></li><li>改一個設定 <button class="up" aria-label="改一個設定往上移">↑</button></li><li>做自己的作品 <button class="up" aria-label="做自己的作品往上移">↑</button></li></ul><p id="result" role="status">拖曳清單，或使用 ↑ 按鈕排序。重新整理會還原。</p>

③ 啟動功能

const list = document.querySelector('#tasks');
function report(){ document.querySelector('#result').textContent = '目前順序：' + [...list.children].map(li => li.firstChild.textContent.trim()).join(' → '); }
new Sortable(list,{animation:150,filter:'button',preventOnFilter:false,onEnd:report});
// 另外提供按鈕，讓鍵盤使用者也可以排序。
list.querySelectorAll('button').forEach(button => button.onclick = () => {
  const li = button.parentElement;
  if(li.previousElementSibling) list.insertBefore(li,li.previousElementSibling);
  button.focus(); report();
});

範例固定版本，方便重複練習；官方文件可能已更新。若改用新版，請對照該版本 API。資料僅在瀏覽器示範。
