DEMO 07 / 輪播展示

Swiper

讓一組卡片可以左右切換。像商品介紹、活動照片，不需要自己寫拖曳邏輯。

new Swiper()

動手試試

拖曳卡片或點左右箭頭，切換三張學習卡片。

01 · 先認識 HTML
02 · 用 CSS 排版
03 · 用 JS 加上互動

讀懂這個範例

先用 HTML 放好畫面，再載入外掛的 CSS（若有）與 JavaScript，最後執行下面的初始化程式。把這個 HTML 檔複製一份，改設定練習。

① 引入外掛

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/swiper@11.2.6/swiper-bundle.min.css">
<script src="https://cdn.jsdelivr.net/npm/swiper@11.2.6/swiper-bundle.min.js"></script>

② 準備畫面

<div class="swiper"><div class="swiper-wrapper"><div class="swiper-slide">01 · 先認識 HTML</div><div class="swiper-slide">02 · 用 CSS 排版</div><div class="swiper-slide">03 · 用 JS 加上互動</div></div><div class="swiper-pagination"></div><div class="swiper-button-prev"></div><div class="swiper-button-next"></div></div>

③ 啟動功能

const swiper = new Swiper('.swiper', {
  loop:true,
  keyboard:{enabled:true},
  pagination:{el:'.swiper-pagination',clickable:true},
  navigation:{nextEl:'.swiper-button-next',prevEl:'.swiper-button-prev'}
});
閱讀 Swiper 官方文件 ↗

範例固定版本，方便重複練習；官方文件可能已更新。若改用新版，請對照該版本 API。資料僅在瀏覽器示範。
