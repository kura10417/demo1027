DEMO 10 / 日期處理

Day.js

輕鬆計算日期並統一顯示格式。像今天起算 7 天後交作業，不必自己算跨月。

dayjs()、add()、format()

動手試試

輸入 7 或 30 再計算；使用瀏覽器所在裝置的本地日期。

讀懂這個範例

先用 HTML 放好畫面，再載入外掛的 CSS（若有）與 JavaScript，最後執行下面的初始化程式。把這個 HTML 檔複製一份，改設定練習。

① 引入外掛

<script src="https://cdn.jsdelivr.net/npm/dayjs@1.11.13/dayjs.min.js"></script>

② 準備畫面

<label for="days">幾天後交作業？</label><input id="days" type="number" min="0" max="365" step="1" value="7"><button id="calc">計算截止日</button><p id="result" role="status"></p>

③ 啟動功能

function calculate(){
  const input = document.querySelector('#days');
  if(!input.reportValidity() || input.value === '') return;
  const days = Number(input.value);
  document.querySelector('#result').textContent = '今天 ' + dayjs().format('YYYY/MM/DD') + '；截止日 ' + dayjs().add(days,'day').format('YYYY/MM/DD');
}
document.querySelector('#calc').onclick = calculate;
calculate();
