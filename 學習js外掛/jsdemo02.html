DEMO 02 / 資料呈現

Chart.js

把數字畫成圖表。像每週讀書時間，長條越高就表示花的時間越多。

new Chart()、chart.update()

動手試試

按按鈕看圖表更新；試著將 type 改成 line。

讀懂這個範例

先用 HTML 放好畫面，再載入外掛的 CSS（若有）與 JavaScript，最後執行下面的初始化程式。把這個 HTML 檔複製一份，改設定練習。

① 引入外掛

<script src="https://cdn.jsdelivr.net/npm/chart.js@4.4.8/dist/chart.umd.min.js"></script>

② 準備畫面

<div style="height:300px"><canvas id="chart" aria-label="每週學習分鐘長條圖" role="img"></canvas></div><button id="change">換一組練習資料</button>

③ 啟動功能

const chart = new Chart(document.querySelector('#chart'), {
  type: 'bar',
  data: { labels: ['週一','週二','週三','週四','週五'], datasets: [{label:'學習分鐘',data:[20,35,25,50,40],backgroundColor:'#247c72'}] },
  options: { responsive:true, maintainAspectRatio:false, scales:{y:{beginAtZero:true}} }
});
document.querySelector('#change').onclick = () => {
  chart.data.datasets[0].data = Array.from({length:5}, () => 10 + Math.floor(Math.random()*51));
  chart.update(); // 改資料後，請圖表重新畫一次。
};
閱讀 Chart.js 官方文件 ↗

範例固定版本，方便重複練習；官方文件可能已更新。若改用新版，請對照該版本 API。資料僅在瀏覽器示範。
