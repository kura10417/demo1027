先知道這幾件事

這裡把「外掛」當成第三方 JavaScript 函式庫的通稱，並非瀏覽器擴充套件。「js 函式名稱」列的是各函式庫提供的常用 API；有些用函式呼叫，有些用 new 建立物件。

雙擊本資料夾的 js.html 即可開始。範例使用固定版本的 CDN，需要網路；不用安裝 npm 或打包工具。地圖另需載入網路圖磚，3D 範例需要 WebGL。

建議先學：日期選擇 → 提示視窗 → 圖表，再探索其他類型。已有 HTML、CSS 與基本 JavaScript 概念會更容易上手。
