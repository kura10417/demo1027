# 2A01 按月合併報表

雙擊「啟動2A01.cmd」，網頁會自動開啟。請保留命令視窗，關閉視窗會停止本機服務。直接雙擊 HTML 會顯示啟動提示。所有資料僅在本機處理，重新啟動後需重新上傳。

1. 拖入多份輸入 Excel，或一份含多個月份工作表的 Excel。
2. 拖入一份輸出樣板，選擇要寫入的工作表。
3. 核對每張輸入工作表的年度與月份，取消不需要或重複的工作表。
4. 產生預覽，核對數字及警示，勾選確認後下載 xlsx。

## 配對方式

適用於附件 CH5-1 的 TIPC 表格。輸入表頭需含「貨物群組代碼」「貨物代碼」，下一列含兩個「噸數」欄，分別代表裝貨與卸貨。使用這兩欄相加，不依賴 M 欄公式快取。其他欄位如艘次、工時不納入噸數。輸出以相同群組與貨物代碼配對，表頭需有「1月」至「12月」等月份名稱。允許貨物列與月份欄重新排列。表頭可位於前 30 列，不要求固定座標。

輸入與輸出不必有相同工作表名稱。樣板有多張工作表時，一次選擇一張寫入，其餘工作表原樣保留。若更換樣板的欄位語意（例如改成工時而非噸數），需調整配對程式，不能任意猜測。

已匯入月份未出現的貨物填 0，未匯入月份留白。樣板月份明細區原有數值會被取代；公式明細區會阻擋處理，避免破壞公式。樣板未包含的來源貨物會列出警示，不會新增資料列。合併前請確認樣板涵蓋所有需要的貨物。

同一月份多張工作表預設阻擋，避免月報與多月檔重複計算。只有確定是不同批次時，才勾選允許同月加總。相同檔案內容的同一張工作表即使改名上傳也會阻擋。民國年與西元年目前不自動互換，請使用樣板的年度表示法。

## 格式與相容性

- xlsx：以原始 ZIP 檔為基礎，只替換選定工作表月份明細的數值 XML。樣式、字體、背景、合併儲存格、欄寬列高、列印設定、圖片及其他工作表元件不重新產生。
- xls：需要 LibreOffice（本機已安裝），會先轉為 xlsx。轉換可能改變舊版格式、圖片、字型或列印結果，**無法保證 xls 原格式完全一致**；要求嚴格格式時，請先在 Excel 將樣板另存成 xlsx 並確認版面。
- 網頁預覽不等同 Excel 列印預覽，不呈現圖片、條件格式、完整數字格式及所有主題色。下載檔保留 xlsx 樣板原始元件，請在 Excel 核對實際列印結果。
- 不支援密碼加密檔、xlsm、巨集、明細輸入噸數中的公式。下載統一為 xlsx。
- 本機處理程式使用 Python 3、openpyxl；啟動器優先使用此電腦 Codex 內附 Python，其他電腦可安裝 Python 與 openpyxl 後啟動。
- 每份上傳上限 40 MB。服務只監聽 127.0.0.1 的隨機連接埠，使用隨機存取權杖。暫存資料於正常關閉服務後清除，不應分享本機網址給其他人。
