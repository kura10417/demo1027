# 待辦事項管理

一個不需安裝或登入的單頁待辦事項管理工具。直接以瀏覽器開啟 `index.html` 即可使用。

## 功能

- 新增工作，並設定截止日期與高、中、低優先順序。
- 將工作標記為未開始、進行中或已完成，並保留完成時間。
- 依工作狀態篩選，或依優先順序、截止日期、建立日期排序。
- 編輯或刪除既有工作。
- 將未完成工作加入「今日聚焦」，可設定 3、4 或 5 件上限，也可從工作清單拖曳加入。
- 由左上角選單調整小、標準或大字體，並保留偏好設定。
- 切換明亮與深色模式，讓介面符合使用環境。
- 切換編輯模式與聚焦模式；聚焦模式只顯示當日聚焦事項。
- 點選「新增待辦」以燈箱填寫內容；點選待辦列或今日聚焦卡片即可開啟燈箱編輯。
- 顯示全部、未完成與已完成工作的統計數字。
- 使用瀏覽器 Local Storage 儲存資料；同一瀏覽器再次開啟時會保留待辦與當日聚焦設定。

## 使用方式

1. 開啟 `index.html`。
2. 在「新增工作」填入工作內容，可選填截止日期並選擇優先順序。
3. 使用工作列的「加入聚焦」、狀態選單、編輯與刪除按鈕管理項目。
4. 需要專心完成當日工作時，從左上角「選單」切換至聚焦模式。
5. 在燈箱外的遮罩區點擊即可關閉燈箱，不會儲存未提交的異動。

## 專案結構

- `index.html`：目前正式版本（v1.0）。
- `history/`：歷史版本原始檔。
- `CHANGELOG.md`：版本變更記錄。

## 資料說明

待辦資料只保留在目前瀏覽器的 Local Storage。清除瀏覽器網站資料、以無痕模式使用，或改用不同瀏覽器／裝置時，不會帶入原有待辦。

## 版面與模式

- 頂端將主標題、版本號與新增待辦整合在同一列，節省垂直空間。
- 編輯模式以「今日聚焦」與「待辦清單」雙欄呈現；螢幕較窄時會自動改為單欄。
- 聚焦模式只顯示今日聚焦區域，左上角選單仍可隨時使用。

## CSV 資料

匯入與匯出均採用附件定義的 10 欄 CSV 標準格式。匯入會取代現有待辦資料，任務編號由系統保存且不顯示在介面。畫面日期使用 `YYYY/MM/DD`，CSV 使用 `YYYY-MM-DD`。
